**Status:** Accepted

## Learning Reflection
Improved database query efficiency by leveraging the GROUP BY clause to group teacher subjects by teacher, allowing for efficient aggregation of unique subjects taught by each teacher.

Utilized the COUNT(DISTINCT) function to count the number of unique subjects taught by each teacher, effectively handling cases with duplicate subjects.

This solution showcases the ability to apply basic SQL aggregation functions to solve a problem, emphasizing a fundamental concept in database query optimization.
