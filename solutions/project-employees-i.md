# Project Employees I

**Status:** Accepted
**Language:** mysql
**Date:** 2025-12-05

## Learning Reflection
Implemented a solution for the "Project Employees I" problem by utilizing a self-join SQL query to establish a many-to-many relationship between the Employees and Projects tables based on the Employees' project_id. This approach allowed for efficient querying of an employee's project count. The use of a self-join demonstrates a key concept in database querying: joining the same table multiple times to facilitate complex relationships.
