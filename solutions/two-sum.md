# Two Sum

**Status:** Accepted
**Language:** java
**Date:** 2025-12-05

## Learning Reflection
Implemented a solution to the "Two Sum" problem using a hash table to achieve a time complexity of O(n) by storing the numbers we have seen so far and their indices. This approach allows us to efficiently look up the complement of a target sum in constant time. The use of a hash table here is a classic example of a "dictionary" data structure in algorithmic problem-solving.
